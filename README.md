# Hollowbloom

Gothic, color-soaked cryptid fursuit commission card.

Starting prices, a menagerie of six original cryptids, and a live quote you can save on this device or copy. This is a new project. It does not modify [rampa.fun](https://github.com/ceoempresarial1-cell/rampa-fun).

Hollowbloom does not collect payment. The ledger is for planning a suit.
